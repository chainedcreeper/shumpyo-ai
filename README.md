# 쉼표 AI — 개인 맞춤 수면·스트레스 코치

바이오헬스 × AI 개인화 아이디어 (우송4반 실습, 2026-10-13)

내 워치 데이터(수면·HRV·활동)로 **나만의 기준선**을 학습해, 오늘의 회복 상태를 알려주고 맞춤 수면·휴식 루틴을 추천하는 AI 코치.

🌐 **프로토타입:** https://chainedcreeper.github.io/shumpyo-ai/

## 진행 과정
1. **NotebookLM** — 수면장애 현황·슬립테크·HRV 자료 수집 → 소스 채택 → 슬라이드·동영상 개요
2. **genspark.ai** — 웹앱 프로토타입 제작
3. **GitHub** — REPO 저장 + GitHub Pages 게시

## 프로토타입 기능
- 개인 기준선 학습 (첫 14일 HRV·수면 평균/편차)
- 오늘의 회복 점수 (기준선 대비 Z-점수)
- 7일 추세 차트, 맞춤 취침 시간 추천
- 원인 분석 리포트 (카페인·운동 ↔ 수면)
- 4-7-8 호흡 가이드, 점수 숨기기(수면 강박 방지)

> 샘플 데이터 기반 프로토타입이며 의료 진단용이 아닙니다.
